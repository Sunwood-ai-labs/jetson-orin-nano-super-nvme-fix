# Contributing

Contributions are welcome when they improve reproducibility, safety, or documentation clarity.

## Good Contributions

- Safer macOS disk-identification steps
- Verified Jetson Orin Nano Super 8GB boot notes
- Official NVIDIA flashing references
- Local LLM measurements with exact model names and runtime evidence
- CI or documentation improvements

## Please Avoid

- Uploading disk images or OS archives
- Publishing credentials, SSH keys, or device passwords
- Replacing official NVIDIA guidance with unsupported claims
- Generalizing results without hardware/runtime evidence

## Local Checks

```sh
npm install
npm run check
```
